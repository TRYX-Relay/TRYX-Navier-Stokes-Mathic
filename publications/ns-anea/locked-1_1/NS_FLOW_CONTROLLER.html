Controller under demonstration

NS Flow uses an evolving signed state balance to predict vortex-core pressure and constrain the pump motor’s rate of speed change. The demonstration exposes the state, forecast, selected command and resulting trajectory.

  1. Inputs: requested flow and calculated flow, motor speed, restriction and core-width state.
  2. Prediction: evolve the signed balance over 0.5 seconds with current motor speed and restriction held fixed in the forecast.
  3. Decision: reduce speed when current pressure breaches the guard; otherwise block positive acceleration when forecast pressure breaches it; otherwise follow flow demand.
  4. Output: a speed-change command bounded to ±200 RPM/s and a motor-speed range of 600–2400 RPM.

Implemented embodiment: simulated pump supervisory speed controller. Motor-drive electronics, sensor acquisition and hardware timing are not implemented in this HTML. The comparator is an independent PI implementation using the referenced MathWorks back-calculation method.

What NS Flow adds
NS Flow evolves the model’s signed enstrophy balance to forecast vortex-core pressure half a second ahead. This gives its protective rule an opportunity to block acceleration before current pressure crosses the guard. The nominal MathWorks-method comparator uses flow error, accumulated error and a current-pressure guard.
